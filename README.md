# AI Learning Portal

All of my learning material around Artificial Intelligence

Web page - https://shrawanika-w.github.io/ai-learning

## Local setup

- Create virtual environment

```text
ai-learning>python -m venv .venv
ai-learning> .\.venv\Scripts\activate
```

- Install requirements.txt

```text
ai-learning>pip install -r requirements.txt
```

- Run mkdocs locally

```text
ai-learning>mkdocs serve
```
