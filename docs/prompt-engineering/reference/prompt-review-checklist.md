# Prompt Review Checklist

Use this checklist for prompts that will be shared or automated.

## Purpose

- Is the task clear?
- Is the intended audience or workflow known?

## Inputs

- Are required inputs defined?
- Is untrusted input separated from instructions?
- Is sensitive-data handling understood?

## Context

- Is required context supplied?
- Is stale or irrelevant context excluded?

## Constraints

- Are important boundaries explicit?
- Are safety and security rules enforced outside the prompt where needed?

## Output

- Is the expected format defined?
- Should a structured schema be used instead of natural-language formatting?

## Validation

- Is there an evaluation set?
- Are failure cases included?
- Is the prompt versioned?
- Is the model version tracked where reproducibility matters?
