# Prompt Cheat Sheet

```text
TASK
What should the AI do?

CONTEXT
What information is required?

CONSTRAINTS
What must or must not happen?

OUTPUT
What should the answer look like?

VALIDATION
How will correctness be checked?
```

## Useful additions

```text
List assumptions before proceeding.
Do not invent missing APIs or requirements.
Use evidence from the supplied code.
Identify uncertainty explicitly.
Do not modify code until the plan is reviewed.
Generate tests from the requirement, not only from the implementation.
```

## Before accepting AI output

- Can I explain it?
- Are assumptions visible?
- Are APIs real?
- Does it follow project standards?
- Are edge cases covered?
- Has it been tested?
- Has security been reviewed?
