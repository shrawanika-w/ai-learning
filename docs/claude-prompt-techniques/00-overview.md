## Main idea

Good prompting is not about a magic phrase.

A strong prompt usually combines:

**clear task + relevant context + constraints + examples when needed + explicit output expectations + evaluation**

## Important

Model behavior changes over time. Re-test important prompts when changing models or model versions.
